
# AIML Honors

A collection of assignments, practicals, and projects completed as part of the AIML Honors program.

## 📚 Assignments and Projects

### Assignment 1: Multi-Gateway Payment Engine

A Python-based payment processing simulation demonstrating Object-Oriented Programming (OOP) concepts and the Factory Design Pattern.

**Features**
- Supports Razorpay and Stripe gateways.
- Supports Card and UPI payment methods.
- Uses abstract classes and inheritance.
- Implements polymorphism and factory-based object creation.
- Handles invalid gateway and payment method selections.

**File:** `multi-gateway-payment-engine.py`

**Run the program**

```bash
python3 multi-gateway-payment-engine.py
```

### Assignment 2: Employee Management System

A menu-driven employee management application that performs CRUD operations using Python, Pandas, and CSV file storage.

**Features**
- Add new employee records.
- Display all employee records.
- Search employees by ID.
- Update employee details.
- Delete employee records.
- Store employee information in a CSV file.

**Technologies:** Python, Pandas, CSV

**Install the dependency**

```bash
python3 -m pip install pandas
```

**Run the program**

After adding your employee management Python file to the repository, run it using its actual filename. For example:

```bash
python3 employee_management.py
```
